# Download und Lizenz

## Türwache herunterladen

Die aktuelle Version findest du unter [GitHub Releases](https://github.com/xKeRnx/tuerwache/releases/latest). Lade `tuerwache-<version>.zip` herunter und entpacke das Archiv. Dort findest du auch die Änderungen und die SHA-256-Prüfsumme des Downloads.

Zur Einrichtung gibt es Anleitungen für [Windows](windows.md), [Linux](linux.md) und den [Raspberry Pi](raspberry-pi.md). Sichere bei einem Update zuerst deine Installation. Die Schritte stehen unter [Betrieb und Sicherheit](operations.md).

## Private Nutzung

Türwache ist für den privaten Gebrauch kostenlos. Der [Quellcode ist auf GitHub einsehbar](https://github.com/xKeRnx/tuerwache). Die [Türwache-Privatnutzungslizenz](../LICENSE.md) beschreibt die Bedingungen für Nutzung, Änderungen und Weitergabe.

## Hilfe und Rückmeldungen

Fragen zur Einrichtung kannst du über die [Kontaktseite](https://tuerwache.de/kontakt/) stellen. Fehler und Funktionswünsche kannst du [auf GitHub melden](https://github.com/xKeRnx/tuerwache/issues). Gib deine Türwache-Version, dein Betriebssystem und die Schritte zum Problem an. Halte Zugangsdaten und Kameraaufnahmen privat.
